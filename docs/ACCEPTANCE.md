# Приёмка на целевом оборудовании

До использования с ценным секретом проверить на тестовых данных.
Исходный загрузчик/разделы проект не должен заменять; используется отдельная
EFI-запись. Место, где EFI вернул ошибку, прошивка может обработать переходом
к другой записи BootOrder — это не выдаёт секрет, но не означает остановку ПК.

1. Проверить TPM 2.0, SHA-256 bank, Measured Boot при выключенном Secure Boot.
2. Собрать с собственным ключом, добавить initrdctl и получателя в initramfs.
3. Проверить подпись комплекта через initrdctl verify до установки.
4. Установить в новый EFI/TPMBOOT, создать отдельную запись.
5. Первая загрузка должна дать `/tpmboot/enrollment.bin`, но не secret.
6. Явно зарегистрировать тестовые случайные 64 байта из RAM; проверить, что
   sealed.bin появился, enroll.request удалён, исходный секрет не записан на ESP.
7. Вторая загрузка должна передать ровно те же 64 байта потребителю.
8. Выполнить минимум три холодных запуска через ту же запись. Проверить,
   что PCR воспроизводятся без прогноза и секрет доступен.
9. Изменить копию initramfs: EFI должен вернуть ошибку до Unseal.
10. Изменить копию ядра: тот же результат.
11. Изменить манифест/командную строку без подписи: отказ.
12. Загрузить изменённый EFI с тем же контейнером: исходный секрет недоступен.
13. Скопировать EFI-раздел в VM/на ПК с другим TPM: исходный секрет недоступен.
14. После закрытия фазы попробовать открыть исходный объект из Linux,
    используя раннюю policy: отказ из-за изменившихся PCR.
15. Удалить sealed.bin без явной регистрации: новое значение не создаётся.
16. Повредить sealed.bin: отказ без обхода/автоматического переобучения.
17. Проверить успешный запуск ядра через LoadFile2 и отсутствие других
    initrd-провайдеров, влияние выбранной версии Linux EFI stub на память.
18. Отдельно проверить потери питания во время записи первого контейнера.

Записать модель ПК, версию UEFI, TPM производителя/firmware, ядро, конфигурацию,
boot entry и результаты. Профиль одной машины не доказывает совместимость всех
x86-64 платформ. Изменение UEFI/ядра/initramfs требует повторной приёмки.
